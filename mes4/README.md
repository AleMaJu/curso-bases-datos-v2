# API de Gestión de Biblioteca - Mes 4

API REST construida con FastAPI para gestionar una biblioteca (alumnos, libros y préstamos).

## 🚀 Tecnologías

- **FastAPI** - Framework web para APIs
- **PostgreSQL** - Base de datos relacional
- **Pydantic** - Validación de datos
- **Uvicorn** - Servidor ASGI

## 📋 Requisitos

- Python 3.8+
- PostgreSQL 15+
- pip
