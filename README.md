# Curso de Bases de Datos - Mes 3

## Proyecto: Integración de Python con PostgreSQL

### Scripts incluidos:
- `mes3/conexion.py` - Conexión segura a PostgreSQL
- `mes3/leer_alumnos.py` - Leer datos de la tabla alumnos

### Configuración:
1. Crear un archivo `.env` con tus credenciales
2. Instalar dependencias: `pip install psycopg2-binary python-dotenv`

### Tecnologías:
- Python 3
- PostgreSQL
- psycopg2
